# 👕 FlexZone – Clothing E-Commerce Web Application

FlexZone is a full-stack clothing e-commerce web application developed using Java, Hibernate ORM, MySQL, and modern frontend technologies.

The platform provides an online shopping experience where customers can explore clothing products, manage their shopping carts, place orders, and complete payments.

## 🚀 Key Features

- **User Authentication:** User registration, login, logout, and Google authentication.
- **Product Browsing:** Explore clothing collections for Men, Women, and Kids.
- **Product Management:** Manage products, categories, brands, sizes, colors, and stock.
- **Shopping Cart:** Add products to a cart and manage selected items.
- **Checkout System:** Manage delivery addresses and select delivery options.
- **Online Payments:** PayHere payment gateway integration.
- **Order Management:** View order history and track delivery statuses.
- **User Profile:** Manage account information, passwords, and saved addresses.
- **Responsive Interface:** A user-friendly shopping experience across different screen sizes.

## 🏗️ Application Architecture

FlexZone follows a layered application architecture to separate responsibilities and improve maintainability.

**Frontend → REST Controllers → Service Layer → Hibernate ORM → MySQL Database**

- **Frontend:** Handles the user interface and interactions.
- **Controllers:** Process REST API requests and responses.
- **Services:** Handle business logic and application operations.
- **DTOs:** Transfer data between application layers.
- **Entities:** Represent database tables using Hibernate ORM.

- Order Management

## 🎯 Project Objective

The objective of FlexZone is to develop a practical e-commerce platform while applying Java web development, object-oriented programming, REST API development, relational database management, and full-stack software engineering concepts.
